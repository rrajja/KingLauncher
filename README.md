# King Launcher (Android TV / Google TV)

Features: rainbow flashing "Welcome To SARAN Home" title, clock + date, live weather for
Mayiladuthurai (Open-Meteo, no key needed), fast D-pad app grid, Clean Cache, Storage and Settings shortcuts.

## Get the APK (no coding needed)
1. Create a free account at github.com and make a new repository (e.g. `KingLauncher`).
2. Upload ALL files and folders from this project (keep the `.github` folder).
3. Open the repository > **Actions** tab > "Build King Launcher APK" > wait about 3-5 minutes.
4. Open the finished run and download **KingLauncher-apk** (a zip containing `KingLauncher.apk`).

## Install on Xiaomi Google TV
1. Copy `KingLauncher.apk` to a USB drive and plug it into the TV (or use "Send Files to TV").
2. Install a file manager on the TV, open the APK, allow "install unknown apps", install.
3. Press Home and choose King Launcher as default (or open it from the apps row).
   Some Google TV builds do not allow replacing the default home screen; the launcher then
   works as a normal app you open from your apps row.

## Build in Android Studio instead
Open this folder in Android Studio, let it sync, then Build > Build APK(s).
